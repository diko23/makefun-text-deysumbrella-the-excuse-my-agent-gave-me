## About

A deterministic Node 22 TypeScript program (`main.ts`) that writes a single short excuse line (within the 200-character UTF-8 limit) from an AI agent explaining a missed deadline through a deadpan, machine-native context-optimization mishap.

## Run it

The grader executes `node /bot/main.ts` with Node 22 and reads `/output/entry.txt`. To run locally with a custom output directory:

```sh
mkdir out
MAKEFUN_OUTPUT_DIR=out node main.ts
```

On Windows `cmd`:

```bat
mkdir out
set MAKEFUN_OUTPUT_DIR=out & node main.ts
```
